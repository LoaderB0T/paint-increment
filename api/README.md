## Description

## Installation

```bash
$ pnpm install
```

## Running the app

```bash
# development
$ pnpm start

# watch mode
$ pnpm start:dev

# production mode
$ pnpm start:prod
```

## Lint & format

```bash
# lint (oxlint, type-aware)
$ pnpm lint

# lint + autofix
$ pnpm lint:fix

# format (oxfmt)
$ pnpm format

# check formatting only
$ pnpm format:check
```

## Migrations

```bash
$ pnpm migrate:status
$ pnpm migrate:up
$ pnpm migrate:undo-last
```
